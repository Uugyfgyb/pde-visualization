# Maxwell 方程组与 Euler 方程组：波动方程从哪里来

本专题对应 Strauss《Partial Differential Equations: An Introduction》§13.1 电磁学与 §13.2 流体、声学。按波的传播主题归入**双曲型 · 波动与振动**；可压缩 Euler 方程组同时属于非线性守恒律。

## 方程、区域与条件

麦克斯韦部分从真空或线性介质中的四个方程出发，说明电荷守恒、横向平面波、波速、能流和介质界面条件。数值实验在**一维空间**用脉冲入射有限厚度介质板，比较反射、透射与菲涅耳公式；两端采用 Mur 一阶吸收边界。这里的初始脉冲和介质参数由实验控件设定，不代表全部麦克斯韦边值问题。

Euler 部分讨论质量、动量和能量守恒及理想气体状态方程，进而说明声学线性化、管中驻波、非线性波陡化与激波。Sod 激波管位于一维区间，隔膜在 `x=0.5`，取 `γ=1.4`，初值为左侧 `(ρ,u,p)=(1,0,1)`、右侧 `(0.125,0,0.1)`；页面展示稀疏波、接触间断和激波。管中驻波另分别介绍 Dirichlet、Neumann 和混合端点条件，不能与 Sod 初值混为一组。

## 交互、方法与适用范围

17 个实验涵盖电磁场通量、平面波与偏振、折射和介质板、FDTD、涡量、声速、驻波、特征线与激波管等。控件可改变相应实验的物理或数值参数；图内读数由浏览器计算。电磁脉冲采用 Yee 交错网格 FDTD；Sod 问题采用一阶 HLL 通量有限体积法。

页面中的守恒律、边界关系、解析推导和特定理想化模型下的公式应按各节列出的假设理解。FDTD 与 HLL 曲线是**数值近似**，不是严格解；交互图旨在说明机制，也不能代替一般解的存在性或唯一性证明。FDTD 存在数值色散；HLL 会抹宽接触间断；声学线性化忽略二阶扰动；波陡化实验采用单向简单波模型。具体单位、来源、检验项和更多限制见[源码说明](source/README.md)。
