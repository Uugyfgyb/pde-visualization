## 方程、区域和边界条件

矩形 `0<x<a, 0<y<b` 上求 `u_xx+u_yy=0`。上边为 `f(x)=sin(πx/a)+q sin(3πx/a)`，其他三边为零。长方体 `0<x<a, 0<y<b, 0<z<c` 上求 `u_xx+u_yy+u_zz=0`。顶面为 `G(x,y)=f(x)sin(πy/b)`，其余五面为零。两组边界数据都在边角处相容。

矩形解是两个精确分离变量模态之和：

```text
u(x,y) = Σ[n=1,3] Aₙ sin(nπx/a) sinh(nπy/a)/sinh(nπb/a),
A₁=1, A₃=q.
```

长方体解在上式基础上增加 `sin(πy/b)` 与竖直因子 `sinh(κₙz)/sinh(κₙc)`，其中 `κₙ=π√(n²/a²+1/b²)`。每个模态的二阶偏导数之和精确为零。最大值原理和边界条件给出唯一性。

## 操作与读图

| 控件或图 | 含义 |
| --- | --- |
| 区域 | 在矩形曲面与长方体水平切片之间切换。 |
| `a,b,c` | 区域三向边长，均限制在 `[0.6,3]`；矩形不使用 `c`。 |
| `q` | 顶边或顶面中第三正弦模态的无量纲权重，范围 `[-0.8,0.8]`。 |
| `z/c` | 长方体切片相对高度，范围 `[0.05,0.95]`。 |
| 二维热图 | 横轴 `x`、纵轴 `y`；青色为正、粉色为负、白色零值线、紫色其他等值线。矩形上边金线表示施加边界值处。 |
| 三维图 | 矩形图的竖直高度是函数值 `u`；长方体图的竖直高度是真实坐标 `z`，彩色平面是切片，金色顶面是施加边界值处。拖动旋转，滚轮缩放，右键平移。 |

数值与长度均采用无量纲教学约定。颜色每次按当前边界最大绝对值重新缩放，颜色相同并不代表不同参数下函数值相同。图下方实时显示边界采样最值、中心值和两个模态的竖向衰减因子。公式是解析结果；热图、等值线、最值读数和三维网格是离散绘图或采样，并非证明或真实时间演化。

## 验证与范围

运行 `node source/verify.cjs` 检查脚本语法、全部指定边界、四阶差分拉普拉斯残差和页面结构。默认参数下最大残差约 `3.0×10⁻¹⁰`。数值残差受步长和浮点舍入影响；严格的 `Δu=0` 由解析求导得到。

本专题只展示含第 1、第 3 模态的特定边值问题。一般边界数据需要完整傅里叶级数或其他方法；角点不相容时要另外讨论连续性与级数收敛。最大值原理要求有界连通区域及内部调和、闭包连续的解。
