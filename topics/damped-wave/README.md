# 受摩擦阻尼的弦

**分类：**双曲型 · 波动与振动

固定端点的一维弦满足 `u_tt = a²u_xx − cu_t + f(x,t)`。本专题把弦的运动、时空图、能量耗散、初值与外源扰动的稳定性和完整证明放在同一个交互页中。

- [打开单文件交互页](index.html)：无需安装依赖，下载后可离线打开。
- [查看可编辑源码与数学说明](source/README.md)：包含 `engine.js`、原始网页、图片、Python 作图和数值验证。
- [返回 PDE 专题目录](../../index.html)。

数值内核提供模态解析传播子和二阶显式有限差分两种方法；`node tests/check.js` 在 `source/` 目录下完成 18 项检查。页面注明了源项求积、差分插值与古典解假设的限制。
