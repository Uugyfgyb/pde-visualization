# Hopf 最大值原理（边界点引理）

**分类：**椭圆型 · 势场与平衡

设 $B_R(y)\subset\mathbb R^n$ 为球，$n\ge3$；$u\in C^2(B_R(y))\cap C^1(\overline{B_R(y)})$，且 $\Delta u\ge0$。若边界点 $x_0$ 满足 $u(x_0)>u(x)$ 对所有球内点 $x$ 成立，则外法向导数 $\partial_\nu u(x_0)>0$。页面用障碍函数 $v=e^{-\alpha|x-y|^2}-e^{-\alpha R^2}$ 逐步展示证明。

交互包含四个可旋转的 3D 场景和两张随 $\alpha$ 更新的解析曲线。场景以 $n=3$、$R=1$、$\rho=0.5$ 为例；滑块 $0.5\le\alpha\le20$，当 $\alpha>6$ 时，$\Delta v>0$ 才覆盖整个环域。3D 球面是稳态几何示意，不是 PDE 的时间演化或数值解；曲线由给出的解析公式直接绘制。页面标明了辅助函数着色的重新归一化以及曲线纵轴的自动缩放。

源页的定理条件补足了球内 $C^2$ 正则性，并修正了关于强极值原理、Dirichlet 唯一性和一般椭圆算子的过强表述。
