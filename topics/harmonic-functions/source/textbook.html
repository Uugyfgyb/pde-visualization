01 / POISSON FORMULA

圆盘里的边界加权平均

本节符号，先认清再读公式

a、Dₐ
a 与半径为 a 的圆盘a>0 是原圆盘半径，Dₐ 是圆盘内部。本页实验取 a=1；下标 a 标明这个圆盘的半径。
r
内部点到原圆心的距离0≤r<a。它定位正在求值的内部点；不是取平均的小圆半径 R。
ρ
柔：相对距离ρ=r/a，取值 0≤ρ<1，无量纲。ρ=0 在圆心，ρ 越接近 1 越靠近边界。
θ
西塔：内部点的方向角从正 x 轴逆时针量到内部点的方向。滑块显示角度（°），公式运算用弧度；180°=π 弧度。
φ、dφ
斐：边界角；角度积分元φ 从 0 走到 2π，遍历整个圆周。dφ 表示极小的角度宽度。积分时 θ 固定，φ 在变化。
h(φ)
h：边界给定值圆周上方向为 φ 的位置的函数值。h 是已知输入，u 是要计算的内部函数。括号内写的是取值的位置。
Pρ(θ−φ)
P 下标柔：Poisson 核边界角 φ 对内部点的相对权重。下标 ρ 表示核会随相对距离改变；真正的角度权重密度为 Pρ/(2π)。
π、2π
圆周率；一整圈弧度π≈3.14159。2π 弧度等于 360°，所以角度积分从 0 到 2π 覆盖一整圈。
cos、sin
余弦与正弦把角度转为周期变化的数。极坐标转直角坐标时 x=r cosθ、y=r sinθ。cos(nθ) 与 sin(nθ) 在一圈内振荡 n 次。
ψ
普赛：两个方向的角差ψ=θ−φ，只是为简写核公式使用的变量；不是新的位置点。角差可按 2π 周期理解。
n、Σₙ≥₁
模式编号；从 n=1 起求和n=1,2,3,… 是 Fourier 模式的正整数编号，Σ 表示把所有模式加起来。这里的 n 与 Green 恒等式的外法向量 n 含义不同。
uᵣ、uᵣᵣ、uθθ
一阶与二阶偏导数uᵣ 表示只改变 r、固定 θ 时 u 的变化率；uᵣᵣ 再对 r 求一次导数；uθθ 对 θ 连求两次导数。这里的下标表示求导，不是另一个函数。
ρⁿ、r⁻¹、r⁻ⁿ、²
幂与倒数ρⁿ 是 ρ 自乘 n 次；r⁻¹=1/r，r⁻ⁿ=1/rⁿ；上标 ² 表示平方。0≤ρ<1 时，n 越大，ρⁿ 越小。

设 Dₐ = {(r, θ) : r < a}，边界值为连续函数 h(φ)。令 ρ = r/a，圆盘内唯一的调和延拓是：

Poisson 积分公式u(r, θ) = 12π ∫₀²π 1 − ρ²1 − 2ρ cos(θ − φ) + ρ² h(φ) dφ

这条公式怎么读

固定一个内部点 (r,θ)，沿整条边界改变 φ；把每个边界值 h(φ) 乘上它对这个内部点的权重，再累加并除以 2π，得到这个内部点的值 u(r,θ)。

展开推导 · Fourier 模式如何形成 Poisson 核
  1. 极坐标中的 Laplace 方程为 urr + r⁻¹ur + r⁻²uθθ = 0。
  2. 第 n 个角向模式 cos(nθ) 或 sin(nθ) 对应径向因子 rⁿ；在圆心发散的 r⁻ⁿ 项必须舍去。
  3. 把光滑边界数据分解为 Fourier 模式，每个模式向内衰减为 ρⁿ 倍。合并后得到 Pρ(ψ)=1+2Σn≥1ρⁿcos(nψ)；几何级数求和给出上面的分式。
  4. 对任意连续边界数据，用核的正性、归一化和 ρ→1 时的集中性，可证明解趋向给定边界值。唯一性再由最大值原理得到。
名称辨析：这里的 Poisson 公式处理圆盘内的 Δu=0 及指定边界值；带源项的 Poisson 方程是 Δu=f。

05 / ENERGY & UNIQUENESS

同一个恒等式的另一面：能量

本节符号，先认清再读公式

u
函数 u要研究的标量函数。给定一个位置，它返回一个数，例如该位置的温度。图中的数值是无量纲示例。
w
两个解的差在唯一性证明中 w=u₁−u₂，其中 u₁、u₂ 是具有相同边界值的两个调和解；因此 w 的边界值为零。

比较函数；由 λ 指定的比较函数q 与调和解 u 有相同边界值，但内部形状可不同。qλ=x+λ(1−x²−y²) 是本页选用的一族比较函数。

令 v=u，Green 第一恒等式里的内积变成非负的 |∇u|²。这给出 Dirichlet 问题的唯一性，也解释为什么调和解是同边界值函数中的能量极小者。

唯一性

两个同边界值调和解之差记为 w。它在边界为 0。恒等式给出 ∭Ω|∇w|²dV=0，故 ∇w=0；连通区域内 w 为常数，而边界值迫使该常数为 0。

Dirichlet 原理

令 E[q]=½∭Ω|∇q|²dV。若 q 与调和解 u 有相同边界值，交叉项由 Green 恒等式消去，于是 E[q]=E[u]+½∭Ω|∇(q−u)|²dV ≥ E[u]。

单位外法向；外法向导数n 是指向区域外部、长度为 1 的向量；∂ₙu=∇u·n 表示 u 沿向外方向的变化率。它不是对一个叫 n 的坐标求导。
