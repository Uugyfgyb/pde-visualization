## 方程、区域与边界条件

研究调和方程 `Δu=0`。Poisson 实验取二维单位圆盘，连续 Dirichlet 边界值 `u(1,φ)=h(φ)`；其余例子在整个取平均的小圆盘或小球都位于调和区域内时使用平均值性质。强最大值原理要求区域连通，并且内部某点实际达到整个区域的最大值。此处是静态椭圆方程，没有初始条件或真实时间演化。
