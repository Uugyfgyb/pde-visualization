## 1. 能量恒等式（★）—— 正确

以 u_t 乘方程并积分：∫u_tt u_t = ½ d/dt‖u_t‖²；a²∫u_xx u_t = a²[u_x u_t]_0^l − a²∫u_x u_xt = −½a² d/dt‖u_x‖²。
边界项确实消失：由 u(0,t)≡u(l,t)≡0 对 t 求导得 u_t(0,t)=u_t(l,t)=0（古典解 u∈C² 保证该求导合法）。故

  dE/dt = −c∫u_t² dx + ∫f u_t dx，E(t) + c∫_0^t∫u_t² = E(0) + ∫_0^t∫f u_t 。

**结论：正确**（分部积分与边界项论证无漏洞；积分形式与微分形式一致）。

## 2. 定理 1（E 单调不增；非平凡初值严格递减）—— 正确，无漏洞

"E(t₀)=E(0) ⇒ u_t≡0 ⇒ φ≡0"这一步成立，逐环节：
1) 单调性给 E≡E(0) 于 [0,t₀]；2) 对 (★)（f≡0）在 [0,t₀] 积分得 c∫∫u_t² = E(0)−E(t₀) = 0；
3) u_t² 连续且 ≥0，积分为 0 ⇒ u_t≡0；4) 于是 u_tt≡0（t∈(0,t₀)），代回方程得 a²φ''=0，结合 φ(0)=φ(l)=0 得 φ≡0；
5) ψ=u_t(·,0)=0，故 u≡0、E(0)=0，与 (φ,ψ)≢(0,0) 矛盾。
需要且只需要"古典解 ⇒ u_t 在闭板条上连续"这一条，题设已给。

## 3. 定理 2（唯一性）—— 完备（古典解类中不需要额外正则性）

w=u₁−u₂ 是古典解（线性性），满足齐次方程、齐次边界与零初值；E_w(t) ≤ E_w(0) = ½(‖w_t(·,0)‖²+a²‖w_x(·,0)‖²) = 0
⇒ E_w≡0 ⇒ w_t≡0 且 w_x≡0 ⇒ w 只依赖 t ⇒ 由 w(0,t)=0 得 w≡0。
**结论：在页面明确声明的"古典解类"中完备，无需 H²/相容性等额外假设。**
保留意见（表述而非证明）：定理 4 后的注记说"定理 2、3、4 合起来就是适定性：解**存在**且唯一"——存在性并未被这三条定理证明，
且古典解存在还需要相容性条件（φ∈C²、φ(0)=φ(l)=0、φ''(0)=φ''(l)=0、ψ(0)=ψ(l)=0 及与 f 的匹配）。建议改为"唯一 + 连续依赖（适定性的两部分）"。

## 4. 定理 3（对初值稳定性）—— 常数 l²/(π²a²) 与 1 均**正确，且已是最优**

推导：E_w(t) ≤ E_w(0)=½(‖δψ‖²+a²‖δφ'‖²)，Poincaré ‖w‖² ≤ (l²/π²)‖w_x‖²，‖w_x‖² ≤ 2E_w/a²
⇒ ‖w‖² ≤ (l²/(π²a²))·2·½(‖δψ‖²+a²‖δφ'‖²) = (l²/(π²a²))(‖δψ‖²+a²‖δφ'‖²)；
‖w_t‖² ≤ 2E_w ≤ ‖δψ‖²+a²‖δφ'‖²。**两个常数与页面完全一致。**
尖锐性（自研解，δφ=A sin(πx/l)、δψ=0）：比值 = 1.0000000000000002（t=0）；模式 m 时为 1/m²（m=2 实测 0.25）。
故 l²/(π²a²) **不能再改小**；δφ=0、δψ=B sin(πx/l) 时 ‖w_t(0)‖²/界 = 1.000000。

## 5. 定理 4（对 f 稳定性）—— 每一步不等式与常数均正确

dE_w/dt = −c‖w_t‖²+∫Fw_t ≤ −c‖w_t‖²+‖F‖‖w_t‖ ≤ −(c/2)‖w_t‖²+(1/(2c))‖F‖² ≤ (1/(2c))‖F(t)‖²。
Young 不等式取 a=‖w_t‖,b=‖F‖、系数 c/2 与 1/(2c) 正确；丢掉 −(c/2)‖w_t‖² 方向正确（非正）。
积分并以 E_w(0)=0 得第一式；再乘 Poincaré 链得 L² 常数 (l²/(π²a²))·2·(1/(2c)) = l²/(π²a²c) 与 ‖w_t‖² 常数 1/c。**全部正确。**

- 修正：Asrc 乘 (l/2)（或改用 self.src 的 L² 范数）；fig2 面板 (b) 与 evidence.json 需重跑。

### 8.2（表述）"适定性 = 解存在且唯一"
定理 2/3/4 只给出唯一性与连续依赖，未证明存在性。建议改写（详见第 3 节）。

### 8.3（适用范围）"观测衰减率 ≈ c / 模态能量 ~ e^{−ct}"
该结论只在**欠阻尼**（c < 2aπ/l，即所有模态满足 λ_n > c/2）时成立，对首模态即 c < 2πa/l ⟺ γ=cl/(2πa) < 1，与注记 6 的限制一致 —— 因此**注记 6 内部自洽**。
但交互面板 (c) 对任意滑块组合都并列显示"观测衰减率"与"参考：c"。反例（滑块范围内 c=2, l=2, a=0.4，γ=1.59>1）：自研解实测 ln(E(0)/E(t))/t = 0.4440（t=60 与 t=120 均如此），而 c=2；理论值 c−2√(c²/4−λ₁²) = 0.4442 与之吻合。建议面板在 γ≥1 时提示"强阻尼下衰减率由慢模态决定，不再 ≈ c"。

### 8.4（措辞，非错误）
定理 4 证明中把 ‖w_t‖² ≤ 2E_w(t) 也称作"Poincaré 不等式"（它只是 E_w 的定义）；注记 6 中 "−c(1−γ)E ≤ −κH" 隐含用了 E ≥ H/(1+γ)，未写明。均为表述问题。

### 8.5（可忽略）
check.js 第 4 项用 N=250 截断的 E_w(0) 代替解析的 ½(‖δψ‖²+a²‖δφ'‖²)；因截断只删掉正项，E_w(0)_截断 ≤ 真值，该检查偏保守，不构成问题。
